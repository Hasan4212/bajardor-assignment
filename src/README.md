# বাজার দর (BazarDor)

## Short Description
BazarDor is a web application that helps users check daily market prices of products in Bangladesh, explore product categories, and track price changes easily.

## Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS
- daisyUI
- Better Auth
- MongoDB

## Key Features
1. View daily market prices of products.
2. Browse products by category.
3. Sort products by price from low to high or high to low.
4. Track price increases and decreases with percentage indicators.
5. User authentication with sign up, sign in, and profile management.
